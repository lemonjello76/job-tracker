# Scout pull — E-commerce automation playbook (n8n + GoHighLevel)

> Pulled from Google Drive (`Automation & Content Strategy - Leveraging Your Tech
> Stack`, Nov 2025). Older find, captured now so it's in the vault. A full
> automation blueprint for a physical-product (3D-printed) e-commerce business.

**Tech arsenal:** n8n (self-hosted automation), GoHighLevel (CRM/funnels),
Blender (3D product renders), Insta360 (content), Claude + Cline (build tools).

## 7 n8n workflows (≈1,957 hrs / ~$84k labor value)
1. **Order processing** — parse order → production queue → GHL CRM → ShipStation
   label → confirmation → inventory → review request.
2. **Social distribution** — one upload → compress + auto-post TikTok/Reels/
   Shorts/FB with platform captions → track engagement.
3. **Inventory & production** — daily 6am: sales velocity → priority print queue
   → reorder alerts → sync Etsy/Shopify stock.
4. **Customer service** — AI categorizes inquiries → auto-reply common Qs → GHL
   ticket for complex → flag complaints/returns.
5. **Wholesale lead nurture** — inquiry → GHL pipeline → catalog → Day 3/7/14
   follow-up → hot-lead alerts → auto-quote.
6. **Review/testimonial collection** — 7 days post-delivery → review request +
   10% code → photo/video ask on 5-star → damage control on negative.
7. **Dynamic pricing** — weekly: find slow movers → auto discount codes → update
   stores → email + social.

## GHL funnels
- **D2C:** "Party Like It's 1776" themed (patriotic 3D-printed products), Blender
  renders, bundle builder, upsells, exit-intent, abandoned-cart recovery.
- **Wholesale:** bulk pricing → catalog → sample order → qualification → call.
- **Content-to-commerce:** "As Seen On TikTok" → single-product spotlight →
  one-click checkout.
